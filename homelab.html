Self-Hosted Homelab & AI Camera NVR

Running Dell OptiPlex 5070 · Ubuntu LTS · 6 Docker Services · November 2026

I repurposed a compact Dell OptiPlex 5070 desktop into a local, subscription-free home server running six Dockerized services: network-wide DNS ad-blocking, self-hosted music streaming, MQTT messaging, container management, smart-home orchestration, and an Intel iGPU-accelerated AI Network Video Recorder (NVR).

The main engineering challenge was building a privacy-first local NVR pipeline with Frigate and Home Assistant using zero cloud subscriptions. Most of the work went into hardware-accelerated video decoding, cross-device mobile codec compatibility, a custom Python microservice for hardware camera controls, encrypted VPN access, and reliable push notifications over cellular data.

Host Hardware & Storage

Compute & Graphics

  • Machine: Repurposed Dell OptiPlex 5070
  • CPU: Intel Core i5-8500 (6 cores / 6 threads @ 3.00 GHz)
  • iGPU: Intel UHD Graphics 630 passed into Docker via VAAPI and OpenVINO for video decode and local inference
  • RAM: 8 GB DDR4 (about 3.1 GiB active across all 6 containers)
  • Networking: Gigabit Ethernet with key-based SSH administration

OS & Storage Layout

  • OS: Ubuntu LTS with Docker Compose stacks
  • Boot Drive: NVMe SSD dedicated to the OS and container images
  • Data Drive: Dedicated 1 TB SATA HDD for NVR media retention, smart-home state, MQTT data, and personal music library
  • Remote Access: Encrypted WireGuard mesh VPN with zero exposed router ports

Video Pipeline & Automation

Multi-Stream Pipeline (4K Recording vs. Mobile Decode Limits)

High-resolution streams (4608x1728 H.265) are recorded directly from go2rtc with zero video re-encoding to keep CPU usage low. During testing, streams wider than 4096px caused infinite loading spinners on certain mobile Android WebViews due to hardware decoder limits. Splitting live viewing into an on-demand 2560x960 H.264 stream with Opus audio solved cross-device playback while keeping raw recordings untouched. Object detection runs separately on a lightweight 5 fps sub-stream via OpenVINO on the UHD 630 iGPU in about 11-13 ms per frame.

RTSP Stream Hardening & Zone Filtering

Where audio is not needed, go2rtc strips audio tracks and backchannels directly at the RTSP SDP handshake (#media=video). To cut false alerts from passing traffic and night-time headlight glare, polygon detection zones and exclusion masks were tuned against real daytime and night-time capture logs alongside per-object area and confidence thresholds.

Custom Camera Microservice & Night-Mode State Machine

Because Frigate does not natively expose every vendor-specific hardware control, I built a small Python microservice and web UI integration that persists across container restarts. It checks HSV color saturation on local snapshots to tell IR night mode from daylight without adding extra camera load, overrides conflicting firmware auto-light behavior, and enforces cooldown timers after manual toggles and IR-cut transitions so the light never oscillates in a feedback loop.

Cellular Snapshot Alerts & DHCP Self-Healing

To get lock-screen snapshot previews over cellular data without opening router ports or exposing the NVR, notifications serve short-lived, unguessable 128-bit random URLs through a read-only tunnel. On the network side, critical PoE hardware uses static addressing while Wi-Fi cameras are monitored by a lightweight watchdog script that automatically updates the NVR config if a router reassigns a DHCP lease.

Key Troubleshooting Milestones

Issue Root Cause Fix
Container crash loop YAML indentation misplaced the detect: block alongside a stream path typo. Fixed YAML hierarchy, validated with Frigate's config parser, and added an explicit OpenVINO model config.
UI disconnect & session exhaustion Reverse-proxy edit broke WebSocket proxying, and rapid polling hit the camera's concurrent session cap. Isolated the custom API service, restored WebSocket routing, and added 1-hour API token caching.
Infinite spinner on mobile Wide 4K H.265 main stream exceeded mobile WebView hardware decode width limits. Separated the raw 4K recording stream from an on-demand 2560x960 H.264 live stream.
Playback stutter & stalls Slow keyframe intervals (GOP) and inconsistent RTSP timestamps caused periodic decoder stalls. Tuned camera GOP to 1, capped bitrate, and added -fflags +genpts+discardcorrupt to FFmpeg inputs.
Home Assistant integration bug Upstream integration passed a deprecated via_device key during device registration. Patched the deprecated key out of the custom component so new entities registered cleanly.
YOLOX-s vs. MobileNetV2 YOLOX-s ran ~71 ms on the UHD 630 iGPU and triggered detector overload warnings. Benchmarked both and stayed on ssdlite_mobilenet_v2 (~11 ms) paired with tuned zone masks and area filters.
