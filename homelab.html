Self-Hosted Homelab & AI Camera NVR

Running Dell OptiPlex 5070 · Ubuntu 26.04.1 LTS · 6 Docker Services · November 2026

I repurposed a compact Dell OptiPlex 5070 desktop into a fully local, subscription-free home server running six Dockerized services: network-wide DNS ad-blocking, self-hosted music streaming, MQTT messaging, container management, smart-home orchestration, and an Intel iGPU-accelerated AI Network Video Recorder (NVR).

The biggest engineering focus was building a privacy-first, multi-camera security system using Frigate NVR and Home Assistant with zero cloud subscriptions. Along the way I solved hardware-accelerated video decoding, cross-device Android codec compatibility, custom camera API control for spotlights and sirens, remote VPN access, cellular push notifications with lock-screen snapshots, and self-healing DHCP tracking.

Camera & NVR Engineering

Multi-Stream Pipeline (4K Recording vs. Mobile Compatibility)

The Reolink Duo 2 PoE records its native 4608x1728 H.265 stream at 20 fps directly from go2rtc with zero video re-encoding. For live viewing, however, 4608px exceeds the 4096px hardware decode limit of several Android WebViews (causing infinite loading on a Motorola Edge). Splitting live view into an on-demand 2560x960 H.264 stream with Opus audio and PCMU 2-way talk fixed mobile playback while keeping full 4K recordings untouched. Object detection runs on the lightweight 1536x576 sub-stream at 5 fps on the UHD 630 iGPU in 11-13 ms.

Video-Only Indoor Camera & Yard Zoning

The indoor Tapo window camera uses #media=video in go2rtc so audio tracks and backchannels are rejected at the RTSP SDP handshake, with recording disabled so it only sends snapshot push alerts. Outside, a polygon yard zone and road/neighbor masks block street traffic, tuned using daytime and night-time captures (including a 3-4% downward bounding-box shift from headlight glare) alongside per-object area and confidence thresholds.

Custom Reolink Microservice & IR-Conditional Spotlight

Because Frigate does not natively control Reolink spotlights or sirens, I wrote a small Python microservice (reolink_controller.py) and an injected UI script (reolink_ui.js) persisted via a 1-minute host cron job. It analyzes HSV color saturation on Frigate's local snapshot to detect IR night mode without adding camera load, locks firmware WhiteLed.mode = 0 so manual toggles never fight the camera, triggers the spotlight only on verified yard detections at night, and enforces a 60s manual-off cooldown plus a 15s IR-cut settling delay to stop color-to-IR feedback loops.

Cellular Snapshot Alerts & Self-Healing Networking

To deliver rich lock-screen snapshot alerts over cellular data without opening router ports or exposing Home Assistant, a sync script reads registered mobile devices and sends high-priority FCM pushes pointing to ephemeral, one-time 128-bit random URLs (/public_snap/<32-hex>.jpg) on a read-only local port behind a cloudflared Quick Tunnel. The Reolink stays locked to a static IP, while a 1-minute watchdog scans ports 554 and 2020 to auto-update config.yml if the router ever reassigns the Tapo camera's DHCP address.

Key Troubleshooting Milestones

Issue Root Cause Fix
Frigate crash loop (2,767 restarts) YAML indentation put detect: at 2 spaces instead of 4, plus a stream name typo. Fixed YAML hierarchy, validated with FrigateConfig.parse_yaml, and added an explicit OpenVINO model block.
Greyed-out UI & Reolink error -5 NGINX edit broke mqtt_ws port 5002, and 1-second login polling exhausted camera session slots. Moved custom API to isolated port 15080, restored mqtt_ws, and added 3600s token caching.
Infinite spinner on Android 4608x1728 H.265 main stream exceeded Android WebView 4K decode limits. Split garage_cam_raw (4K H.265 record) from garage_cam (on-demand 2560x960 H.264 live view).
Playback stutter (11 stalls/hr) Slow keyframes (gop: 2/4), high bitrate, and erratic RTSP timestamps. Set gop: 1, 6144 kbps main stream, 10 fps sub-stream, and added -fflags +genpts+discardcorrupt.
HA 2026.10 2nd camera error Custom Frigate integration passed deprecated via_device in device_info. Patched out the deprecated via_device key so camera.window_cam registered cleanly.
YOLOX-s vs. MobileNetV2 YOLOX-s took ~71 ms on the UHD 630 iGPU and triggered overload warnings. Kept ssdlite_mobilenet_v2 (~11 ms) paired with tuned area/score filters and zone masks.
Security & Privacy: Zero router ports are forwarded to the public internet. Remote admin and live camera viewing run exclusively over encrypted Tailscale WireGuard tunnels, and cellular alert snapshots use one-time 128-bit read-only tokens.
